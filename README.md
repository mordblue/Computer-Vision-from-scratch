# Computer-Vision-from-scratch
Exploring computer vision through mathematical foundations, neural networks built from scratch, and reproducible machine learning experiments in Python.


## About the Project

This project explores the mathematical foundations, algorithms, and practical implementation of computer vision and artificial neural networks.

The initial objective is to develop a neural network capable of recognizing handwritten digits using supervised machine learning.

Rather than relying exclusively on existing deep learning frameworks, the focus is on understanding and implementing the underlying algorithms from scratch.

## Objectives

- Understand the mathematical foundations of artificial neural networks.
- Implement machine learning algorithms in Python.
- Develop forward propagation and backpropagation from scratch.
- Investigate different activation functions and optimization algorithms.
- Train and evaluate neural networks on image datasets.
- Conduct reproducible experiments and analyze their results.
- Compare custom implementations with established machine learning frameworks.

## Dataset

The initial experiments will use the MNIST dataset, which contains grayscale images of handwritten digits from 0 to 9.
